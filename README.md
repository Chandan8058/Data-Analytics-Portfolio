# Spotify Power BI Dashboard

## Project Overview

This project is an interactive Spotify dashboard built using Microsoft Power BI.

## Tools Used

- Power BI
- Power Query
- DAX

## Dashboard Features

- KPI Cards
- Top Artists
- Top Songs
- Interactive Filters
- Artist Analysis
- Song Analysis

## Dataset

Spotify Top 50 World Dataset
